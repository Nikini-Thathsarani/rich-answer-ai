# Rich Answer AI

AI Assistant for Technical Manuals

## About the Project

Rich Answer AI is an AI-powered chatbot designed to answer
questions from technical manuals.

Unlike a normal chatbot, the system is designed to provide
rich answers by showing relevant text, diagrams, images,
and tables from the technical manual.

## Main Features

- Upload technical manuals
- Ask questions about the manual
- AI-powered answers
- Display relevant diagrams
- Display relevant images
- Display relevant tables
- Show the source page of information

## Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- OpenAI API
